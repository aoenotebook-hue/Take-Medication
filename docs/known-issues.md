# Known limitations and release gates

- No Supabase project credentials, real VAPID subscriptions or staging HTTPS host were supplied. Their integration code and configuration exist, but live managed email delivery, private-storage policy, real push acceptance and runtime-role grants need staging verification.
- Physical iPhone/Home Screen, Focus, locked-screen and revoked-permission tests are unrun. No notification display/delivery guarantee or supported iOS test result is claimed.
- Thai PDF font embedding and automated 1/10/30-medicine generation were tested; rendered synthetic PDFs were visually inspected. Native Thai typography/terminology review, VoiceOver and pharmacist/clinician review remain unrun. Secondary operational labels/errors still include English or bilingual text and need the native-language review before an older-adult pilot.
- The initial asset cache is about 1.8 MB uncompressed, including the offline PDF library/font. The PDF library is loaded lazily in the page but precached for offline export. A two-second cached-open pilot target is not yet measured on a physical phone.
- Patient snapshots carry complete medication/event history plus a bounded occurrence window. Large-history payloads require pagination/performance work if usage exceeds the small first-release profile scale. Outbox batches are capped at 50 and occurrence generation at a 62-day request window.
- Future-effective changes cannot rewrite historical instructions. The review form offers “when the server confirms” for an immediate change, or an explicit selected timestamp. A selected timestamp arriving after its effective time is disputed rather than silently altering history; review it and choose a new timestamp. Historical events remain immutable.
- A DST gap blocks that schedule's generation and reports an error rather than shifting an instruction. The worker isolates the affected medication, records a nonsensitive review issue and continues refreshing other medications; monitoring alerts on the issue. Resolve unsupported gap times through an explicitly confirmed regimen; no automatic fallback clock time is selected. This still needs staging operations testing with a non-Bangkok profile.
- The 15-minute notification freshness default makes a 30-minute snooze unavailable unless the pilot explicitly configures a longer notification window. These are notification defaults, not acceptable medical delay intervals.
- Export uses local PDF download as the sharing fallback. Account JSON exports include records, photo metadata and base64 private photo files. Large exports can consume browser/server memory and should be exercised at pilot scale. Exported files are not password-protected; sharing remains the user's decision.
- Backup encryption and database restore were exercised locally. Production private-object backups, off-host retention, provider-account deletion retries and external alert delivery need operator configuration and drills. Monitoring supplies aggregate checks and exit codes; it does not secretly send messages or provision a monitoring account.
- Browser storage may be evicted. Local health data are readable to someone with access to the unlocked browser profile; IndexedDB is not advertised as encrypted. Previously downloaded caregiver information cannot be recalled while offline.
- Sign-in uses a phone number and a user-chosen 4-digit PIN without SMS verification, at the owner's request. A 4-digit PIN has only 10,000 values; protection relies on per-number lockout (5 tries, then 15 minutes doubling to 24 hours), per-connection rate limits and server-side peppered scrypt hashes. Anyone can register an unused number, and forgotten PINs need an administrator reset after an out-of-band identity check. Reassess before storing real patient data at scale.
- OCR, escalation, refills, advanced tapers/imports and clinician links are absent/disabled. There are no fake controls claiming these capabilities.

No public site was deployed, real patient information entered, clinical validation performed, or legal compliance asserted. Complete the remaining owner-controlled reviews before a real-patient pilot.
